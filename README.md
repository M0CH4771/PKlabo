# PKlabo — ポケカ買取ラボ オンラインショップ

GitHub Pages（画面）＋ Cloudflare Workers ＋ D1（API・データ）で動く、自前のECサイトです。

国内の主要カードショップEC（遊々亭・カードラッシュ・晴れる屋2・ドラゴンスター等）と TCGplayer を調べ、それぞれの強みを取り込みつつ、どこにもない機能を足しています。

**お客さん向け**
- デッキリストを貼るだけで、在庫から一番安い（または状態の良い）組み合わせをまとめてカートへ
- 同じカードの状態違い（A / B / PSA10 …）を1画面で比較
- 価格推移グラフ、セール表示（値下げ前価格・割引率）
- 商品ページに買取価格を表示して、買取フォームへ誘導
- 高機能な絞り込み（弾・レアリティ・状態・価格帯・セール・実物写真）、ひらがな／カタカナ・全角／半角を区別しない検索
- 実物写真の複数枚表示、在庫数・残りわずか表示
- ログイン不要のお気に入り（登録後に値下がりするとお知らせ）、最近見た商品、売れ筋ランキング
- 入荷通知メール（在庫を戻した瞬間に自動送信）
- 即日発送の締め切りカウントダウン、送料無料まで残りいくらかのバー
- 店頭受け取り（送料無料）、クーポン、配送会社の追跡リンク、注文状況のステップ表示、ブラウザ内の注文履歴
- 支払い：銀行振込（前払い）。Stripe のキーを登録するとカード払いが追加されます

- 会員登録・ログイン・マイページ（注文履歴・住所保存・パスワード再設定・退会）
- ポイント制度（登録ボーナス・還元率・付与タイミング・有効期限・注文での利用・キャンセル時の返却）
- オリパ：総口数・賞ごとの封入数・残り数・確率をリアルタイム公開、注文時にサーバーで抽選、入金確認後に開封演出、ラストワン賞、当選履歴の公開。当選品は実物発送のみ（ポイント等への交換なし）
- 状態違い（A / B / PSA10 …）を1枚のカードとしてまとめて表示し、商品ページで状態を切り替え

**お店向け（管理画面）**
- ダッシュボード（売上・30日グラフ・売れ筋・入荷待ちの多い商品）
- 注文処理：入金確認 → 発送（配送会社＋追跡番号）→ 自動メール。キャンセルで在庫・クーポンを自動で戻す
- ピッキングリスト・納品書の印刷、発送用CSV
- スマホで撮った写真をそのままアップロード（ブラウザで自動圧縮）、商品の複製、CSV一括登録・書き出し
- クーポン（％引き・円引き・最低金額・回数上限・期限）
- **設定タブで全部カスタマイズ**：機能ごとのON/OFF、ショップ名・ロゴ文字・テーマカラー・お知らせバナー、送料・発送曜日・締め時刻、店頭受け取り、振込先、ポイント率・ボーナス・有効期限、オリパの注意書き、カテゴリ、状態表記の説明、特定商取引法の表記
- 商品は「カード」ごとに状態違いをまとめて管理（＋状態で追加、カード名などの共通情報は一括反映）
- CSV 入出力：全項目／在庫・価格だけを書き出し → Excel 等で編集 → 読み込み。ID で更新・ID なしは追加、「更新だけ」モード、在庫の上書き／加算、型番＋状態での照合。Shift_JIS の CSV もそのまま読めます
- 会員管理（検索・ポイント調整・CSV書き出し）、オリパ管理（作成・賞品の写真・還元率の目安・当選履歴）
- 在庫は注文した瞬間に確保、入金期限切れで自動キャンセル（15分ごと）

```
docs/            … GitHub Pages で公開する画面
  index.html     … ショップ（一覧・詳細・カート・購入・注文確認）
  admin.html     … 管理画面
  legal.html     … 特定商取引法に基づく表記・返品・プライバシー
  config.js      … API の URL などの設定
  style.css
worker/          … Cloudflare Worker（API）
  src/index.js
  schema.sql     … D1 のテーブル
  wrangler.toml
```

## セットアップ

### 1. D1 と Worker を作る

```bash
cd worker
npx wrangler login
npx wrangler d1 create pklabo-db
# 表示された database_id を wrangler.toml に貼る
npx wrangler d1 execute pklabo-db --remote --file=schema.sql
npx wrangler secret put ADMIN_KEY      # 管理画面のログインキー（長めのランダム文字列）
npx wrangler deploy
```

送料・振込先・発送曜日などのショップ設定は、デプロイ後に **管理画面の「設定」タブ** から変更できます（`wrangler.toml` の `[vars]` は初期値として使われます）。

既に古いスキーマで D1 を作っていた場合は、テーブルを作り直してください（まだ本番データが無い前提です）。

### 2. 画面を公開する

1. `docs/config.js` の `API_BASE` を、デプロイした Worker の URL（`https://pklabo-api.xxxx.workers.dev`）に書き換える
2. GitHub の Settings → Pages → Branch: `main` / フォルダ: `/docs` で公開
3. `docs/legal.html` の【要記入】を実際の情報に書き換える

公開 URL：`https://m0ch4771.github.io/pklabo/`（管理画面は `/admin.html`）

### 3. 古物商の URL 届出

中古品をネットで販売するので、公開したサイトの URL を、許可を受けた警察署経由で届け出てください。

## Cloudflare 無料プランについて

無料プランは「1回の処理で D1 に問い合わせできるのは50回まで」です。CSV 読み込みは100行ずつ分けて送信、オリパは口数によらず数回の問い合わせで抽選、入金期限切れの自動キャンセルは1回5件ずつ処理するようにしてあります。商品数・注文数が大きく増えたら Workers Paid（月5ドル〜）を検討してください。

## 任意の設定

| 設定 | 内容 |
| --- | --- |
| `STRIPE_SECRET_KEY` | 入れるとカード払いが有効になります（`wrangler secret put`） |
| `STRIPE_WEBHOOK_SECRET` | Stripe の Webhook エンドポイント `https://<worker>/api/stripe/webhook` に `checkout.session.completed` と `checkout.session.expired` を登録して表示される署名シークレット |
| `RESEND_API_KEY` / `MAIL_FROM` | 注文・入金確認・発送・入荷通知のメールを自動送信（Resend でドメイン認証が必要）。未設定だと入荷通知フォームは表示されません |
| R2 バケット `IMAGES` | 商品画像の保存先。設定しなければ D1 に保存されます（小規模ならそのままでOK） |
| `ADMIN_EMAIL` | 新規注文をメールで通知 |
| `DISCORD_WEBHOOK_URL` | 新規注文を Discord に通知 |

メールを設定しない場合も、お客様は注文完了ページ（ブックマーク用URL）で振込先と状況を確認できます。

## 運用の流れ（振込）

1. お客様が注文 → 在庫確保、振込先と注文番号が表示される
2. 通帳・ネットバンクの振込名義の先頭6桁（注文番号）で照合 → 管理画面で「入金確認」
3. 発送したら追跡番号を入れて「発送済みにする」
4. 期限内に入金がない注文は自動で「期限切れ」になり、在庫が戻る

## CSV 一括登録の形式

1行目に見出し（日本語でもOK）：

```
商品名,弾,型番,レアリティ,状態,カテゴリ,価格,値下げ前価格,買取価格,在庫,画像URL,説明,実物写真
リザードンex,黒炎の支配者,201/165,SAR,A,シングル,12800,15800,9000,1,https://...,センタリング良好,1
```

カテゴリは `シングル` / `PSA鑑定品` / `BOX` / `サプライ`（または single / psa / box / supply）。
